# MCSkin3D - 多语言社区增强版 (Multi‑Language Community Edition)

请注意！这个软件需要你有一台 Windows 操作系统的电脑才能运行！
MCSkin3D 是一款 Minecraft 皮肤编辑器。本增强版在原版基础上增加了 11 种界面语言和 25 种错误对照表，方便非英语玩家使用。
本版本基于 Paril 开发的 MCSkin3D 原版，增加了多语言支持，让皮肤编辑器对全球玩家更友好。  
*This version is based on the original MCSkin3D by Paril, with additional language support for a better skin‑editing experience worldwide.*

## 支持的 Windows 操作系统：
· Windows 7：需手动安装 .NET Framework 4.0 或更高版本
· Windows 8、8.1、10、11：原生支持 .NET 4.0+，可直接运行

## 已支持的语言  
English(软件自带)，简体中文 (zh_CN)，繁體中文 (香港)(zh_HK)，澳门繁体 (zh_MO)，台湾正体 (zh_TW)，한국어 (Korean)，Français (French)，Español (Spanish)，Русский (Russian)，Українська (Ukrainian)，Japanese。

## 如何使用  
1. 下载本仓库的压缩包（Releases 页面），或直接下载整个仓库。  
2. 解压到任意文件夹，运行 `MCSkin3D.exe`。  
3. 进入菜单 `Options` → `Language`，选择 `简体中文` 或其他语言。
