MCSkin3D 오류 참조표 (한국어)
==============================

이 문서는 MCSkin3D 사용 중 나타날 수 있는 오류 메시지와 그 원인 및 해결 방법을 정리한 것입니다. 오류 창이 뜨면 이 문서에서 오류 메시지의 키워드를 검색하여 도움을 받으세요.


1. 오류 메시지: 포함된 디렉터리가 없습니다. 일반적으로 프로그램을 압축 해제하지 않았기 때문입니다. 심각한 문제는 아니지만, 포함된 템플릿, 견본 및 기타 콘텐츠가 누락됩니다.
   - 원인: 프로그램이 압축 파일에서 완전히 해제되지 않아 리소스 폴더가 없습니다.
   - 해결: MCSkin3D ZIP 파일을 폴더에 압축 해제한 후 실행하세요. ZIP 파일 안에서 직접 EXE를 실행하지 마세요.

2. 오류 메시지: 스킨 업로드 중 오류 발생:
   - 원인: 네트워크 문제, Minecraft 서버 연결 거부, 또는 사용자 이름/비밀번호 오류.
   - 해결: 인터넷 연결을 확인하고 Minecraft 계정 정보가 올바른지 확인한 후 다시 시도하세요.

3. 오류 메시지: 오버레이 이미지를 로드할 수 없음: "{0}"; 해상도가 2의 거듭제곱이어야 합니다.
   - 원인: 오버레이 이미지의 너비 또는 높이가 2의 거듭제곱이 아닙니다 (예: 16, 32, 64, 128, 256, 512...).
   - 해결: 이미지 편집기로 이미지 크기를 2의 거듭제곱(예: 512x512)으로 조정한 후 `Overlays` 폴더에 다시 넣으세요.

4. 오류 메시지: MCSkin3D로 고해상도 텍스처를 편집할 수 있지만, Minecraft 프로필에 업로드할 수는 없습니다.
   - 원인: 스킨 이미지 크기가 공식 최대 크기(보통 64x64 또는 128x128)를 초과했습니다.
   - 해결: Minecraft는 표준 크기 스킨만 지원합니다. 업로드하려면 해상도를 낮추거나 타사 스킨 서버를 사용하세요.

5. 오류 메시지: 멀티샘플링 옵션을 적용하려면 MCSkin3D를 다시 시작하세요.
   - 원인: 멀티샘플링(안티앨리어싱) 설정을 변경하여 재시작이 필요합니다.
   - 해결: MCSkin3D를 종료하고 다시 실행하세요.

6. 오류 메시지: 죄송합니다. 그래픽 카드가 32비트 픽셀 형식을 지원하지 않는 것 같습니다. 현재 MCSkin3D 실행에 필요합니다.
   - 원인: 그래픽 드라이버가 오래되었거나 하드웨어가 32비트 색상 심도를 지원하지 않습니다.
   - 해결: 그래픽 드라이버를 업데이트하세요. 문제가 지속되면 그래픽 카드를 교체하거나, 다른 스킨 편집기를 사용하거나, 다른 컴퓨터를 시도해 보세요.

7. 오류 메시지: 바로가기 "{0}"이(가) "{1}"과(와) 충돌합니다. 초기화합니다.
   - 원인: 두 가지 다른 기능에 동일한 바로가기 키를 할당했습니다.
   - 해결: `옵션` → `키보드 바로가기`로 이동하여 충돌하지 않는 키를 다시 할당하세요.

8. 오류 메시지: 설정 파일을 불러오지 못했습니다. 기본 설정이 로드되었습니다.
   - 원인: 설정 파일이 손상되었거나 읽을 수 없습니다.
   - 해결: 프로그램 디렉터리에서 `settings.ini` 파일을 삭제하세요(백업이 있으면 복원). 다음에 프로그램을 시작하면 기본 설정이 자동으로 생성됩니다.

9. 오류 메시지: Minecraft 스킨 저장소에서 스킨을 다운로드할 수 없습니다!
   - 원인: 네트워크 문제 또는 Minecraft 스킨 서버 문제.
   - 해결: 인터넷 연결을 확인하고 나중에 다시 시도하세요. 또는 로컬 스킨 파일을 직접 사용하세요.

10. 오류 메시지: 스킨 "{0}"을(를) 불러오는 중 오류 발생. 이 파일을 삭제하거나 폴더에서 옮기세요.
    - 원인: 스킨 파일이 손상되었거나 유효한 PNG 이미지가 아닙니다.
    - 해결: 이미지 편집기로 스킨을 PNG 형식으로 다시 저장하거나, 문제가 있는 파일을 삭제하세요.

11. 오류 메시지: 예외 발생! / 애플리케이션 오류!
    - 원인: 프로그램이 예상치 못한 버그를 만났습니다.
    - 해결: 오류 창 하단의 파란색 링크를 클릭하여 오류 보고서를 복사하고 개발자에게 전송하세요(PlanetMinecraft에서 Paril에게 연락). 프로그램을 다시 시작하거나 컴퓨터를 재부팅한 후 다시 시도해 볼 수도 있습니다.

12. 오류 메시지: 저장하지 않은 변경 사항이 있습니다. 종료하시겠습니까?
    - 원인: 스킨이 수정되었지만 저장되지 않았습니다.
    - 해결: "예"를 클릭하면 저장하지 않고 종료하고, "아니오"를 클릭하면 돌아가서 저장하세요.

13. 오류 메시지: 임시 위치에서 MCSkin3D를 실행하려고 합니다. 프로그램을 올바르게 압축 해제한 후 실행하세요.
    - 원인: ZIP 파일 안에서 직접 EXE를 실행했거나 임시 폴더에서 실행했습니다.
    - 해결: 전체 MCSkin3D 폴더를 하드 디스크(예: 바탕화면 또는 D 드라이브)에 압축 해제한 후 실행하세요.

14. 오류 메시지: 주의: 고해상도 스킨은 Minecraft.net에 스킨으로 업로드할 수 없습니다! 이 작업은 되돌릴 수 없습니다...
    - 원인: 너무 큰 스킨을 업로드하려고 합니다.
    - 해결: 경고입니다. 확인 후 계속 진행하거나, 업로드 전에 "해상도 낮추기" 기능으로 스킨을 축소하세요.

15. 오류 메시지: 저장하지 않은 스킨이 있습니다. 스킨 디렉터리를 변경하면 스킨 목록이 새로고침되어 저장하지 않은 모든 변경 사항이 손실됩니다.
    - 원인: 저장하지 않은 스킨이 있는 상태에서 스킨 저장 경로를 변경하려고 합니다.
    - 해결: 먼저 스킨을 저장한 후 스킨 디렉터리를 변경하세요. 또는 "예"를 클릭하여 강제로 새로고침하고 변경 사항을 잃을 수도 있습니다.

16. 오류 메시지: 이 스킨의 크기가 선택한 모델의 예상 크기와 일치하지 않습니다. MCSkin3D는 다음 두 가지 방법 중 하나로 이 문제를 해결할 수 있습니다: 자르기... 크기 조절...
    - 원인: 스킨 크기(예: 64x64)가 현재 모델 요구 사항(예: 1.8 이중 레이어 스킨은 64x64 또는 128x128 필요)과 일치하지 않습니다.
    - 해결: "자르기" 또는 "크기 조절"을 선택하여 스킨을 변환하세요. 표준 64x64 크기를 사용하는 것이 좋습니다.

17. 오류 메시지: 바로가기 키가 이미 사용 중입니다
    - 원인: 설정한 바로가기 키가 이미 다른 기능에 할당되어 있습니다.
    - 해결: 바로가기 설정에서 충돌하는 기능 중 하나의 키를 변경하세요.


참고: 이 문서는 참고용입니다!

위 목록에 없는 오류가 발생하면 전체 오류 메시지 텍스트를 복사하여 제 GitHub 저장소에 Issue를 제출해 주세요. 분석 후 이 참조표를 업데이트하겠습니다.

MCSkin3D를 즐겁게 사용하세요!
