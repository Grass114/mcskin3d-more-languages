MCSkin3D 多语言增强版 - 使用教程

本教程适用于 v1.4.2 及以上版本！


【1】下载与安装

1. 下载压缩包后，解压到任意文件夹。
   注意：不要直接在压缩包内双击运行，否则会报错。

2. 解压后，双击 MCSkin3D.exe 即可启动。


【2】切换语言（核心功能）

1. 启动软件后，点击顶部菜单 "Options"（选项）。
2. 选择 "Language"（语言）。
3. 在下拉列表中选择你需要的语言：
   - 简体中文
   - 香港繁体 / 澳門繁體 / 台灣正體
   - 한국어 (韩语) / 日本語 (日语)
   - Français / Español / العربية / Русский / Українська
4. 界面会立即切换，无需重启。


【3】界面基本操作

- 左侧：皮肤文件列表（可新建、重命名、删除皮肤）
- 中间：3D 预览区（鼠标右键拖拽旋转，滚轮缩放）
- 右侧：2D 绘图区（像素编辑）
- 底部：色板（快速取色）

快捷键：
  Ctrl+S    保存皮肤
  Ctrl+Z    撤销
  Ctrl+Y    重做
  Ctrl+N    新建皮肤


【4】常见问题

Q: 切换语言后界面没变化？
A: 检查 .lang 文件是否在 Languages 文件夹中，文件编码是否为 UTF-8 无 BOM。

Q: 叠加层加载失败？
A: 图片尺寸须为 2 的幂（如 512x512），调整后重新放入 Overlays 文件夹。

Q: 皮肤上传失败？
A: 确认 Minecraft 账号密码正确，且皮肤尺寸为 64x64 或 128x128。

更多错误请查阅 错误对照表Error comparison table 文件夹中的对照表。
